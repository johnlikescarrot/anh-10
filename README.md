# anh-10

## Đề cương ôn tập giữa học kỳ 1 — Tiếng Anh 10 (Global Success), năm học 2026–2027

📄 **Sản phẩm chính:** [`De-cuong-on-tap-GK1-Tieng-Anh-10-2026-2027.pdf`](De-cuong-on-tap-GK1-Tieng-Anh-10-2026-2027.pdf) (43 trang)

Tài liệu được biên soạn **trực tiếp từ phân tích chuyên sâu** tệp ma trận
[`2026_2027_MA TRẬN 10_GK1.docx`](2026_2027_MA%20TRẬN%2010_GK1.docx) (Ma trận & Bảng đặc tả đề kiểm tra
giữa kỳ 1 môn Tiếng Anh 10, năm học 2026–2027), bám sát:

- **Cấu trúc đề 10 điểm:** Listening 2,5đ (10 câu) • Language 2,5đ (từ vựng + ngữ pháp) •
  Reading 2,5đ (10 câu) • Writing 2,5đ — Trắc nghiệm 70% (28 câu) / Tự luận 30% (6 câu + 1 đoạn văn)
- **Mức độ nhận thức:** Biết 40% — Hiểu 30% — Vận dụng 30% (toàn bộ điểm Vận dụng nằm ở phần tự luận)
- **Phạm vi:** Units 1–3 sách *Global Success 10* — *Family Life*, *Humans and the Environment*, *Music*
- **5 chủ điểm ngữ pháp:** Hiện tại đơn/tiếp diễn; *will & be going to*; Câu bị động; Câu ghép; *To-infinitive & bare infinitive*

### Tái tạo PDF từ mã nguồn

Mã nguồn tạo PDF (Python + ReportLab) nằm trong thư mục [`de-cuong/`](de-cuong/):

```bash
python3 -m venv .venv && .venv/bin/pip install -r de-cuong/requirements.txt
.venv/bin/python de-cuong/build_pdf.py
```

File PDF sẽ được tạo tại thư mục gốc của repo: `De-cuong-on-tap-GK1-Tieng-Anh-10-2026-2027.pdf`.
