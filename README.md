# anh-10

Tài liệu ôn thi giữa học kì 1 môn Tiếng Anh 10 — năm học 2026–2027 (sách Global Success, Units 1–3).

## Nội dung

- `2026_2027_MA TRẬN 10_GK1.docx` — ma trận + bảng đặc tả kỹ thuật đề kiểm tra GK1 (nguồn do nhà trường công bố).
- `on-tap-gk1/DE_CUONG_ON_TAP_GK1_TIENG_ANH_10_2026-2027.pdf` — **đề cương ôn tập bản PDF (sản phẩm chính)**: phân tích cấu trúc đề, từ vựng, 5 chuyên đề ngữ pháp, kỹ năng từng phần, 2 đề ôn luyện đúng ma trận kèm đáp án — giải thích — full tapescript, bảng tra nhanh trước khi thi.
- `on-tap-gk1/PHAN_TICH_MA_TRAN_GK1_10.md` — phân tích chi tiết ma trận và các điểm bất nhất trong tệp gốc.
- `on-tap-gk1/pdf/` — mã nguồn sinh PDF (Python + ReportLab); chạy `python3 build_pdf.py` trong `on-tap-gk1/pdf/` (cần `pip install reportlab`) để tái tạo/tu chỉnh tài liệu.
