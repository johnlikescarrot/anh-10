## 6.2. Bộ 40 cấu trúc viết lại câu "mở rộng"

> 20 mẫu cơ bản đã có ở mục 3.7. Dưới đây là **20 mẫu mở rộng** – mức độ khó hơn, dùng để "ăn điểm tuyệt đối" phần tự luận.

[[W 44 56]]
| Cấu trúc gốc | Viết lại |
|---|---|
| **S + be + too + adj + (for O) + to V** | **S + be + so + adj + that + S + can't + V** |
| *He is too young to drive.* | *He is so young that he can't drive.* |
| **S + be + adj + enough + to V** | **S + be + so + adj + that + S + can + V** |
| *She is old enough to vote.* | *She is so old that she can vote.* |
| **S + spend + time + V-ing** | **S + waste + time + V-ing** / **It takes + O + time + to V** |
| *He spends an hour playing the guitar.* | *It takes him an hour to play the guitar.* |
| **S + prefer + N/V-ing + to + N/V-ing** | **S + like + N/V-ing + better than + N/V-ing** |
| *I prefer tea to coffee.* | *I like tea better than coffee.* |
| **S + would rather + V + than + V** | **S + prefer + V-ing + to + V-ing** |
| *I'd rather stay home than go out.* | *I prefer staying home to going out.* |
| **Nobody + V + as + adj + as + X** | **X + be + the + adj-est + (N)** |
| *Nobody sings as beautifully as Lan.* | *Lan is the most beautiful singer.* |
| **S + began + V-ing + time + ago** | **S + have/has + V3/ed + for + time** |
| *She began teaching ten years ago.* | *She has taught for ten years.* |
| **S + last + V + time** | **S + haven't/hasn't + V3/ed + since + time** |
| *I last saw him in 2020.* | *I haven't seen him since 2020.* |
| **S + V + O + because + clause** | **Because of + N/V-ing, S + V + O** |
| *We stayed home because it rained.* | *Because of the rain, we stayed home.* |
| **Although + clause** | **In spite of / Despite + N/V-ing** |
| *Although he was tired, he finished it.* | *Despite being tired, he finished it.* |
| **S + find + N + adj** | **S + think + N + be + adj** |
| *I find folk music interesting.* | *I think folk music is interesting.* |
| **It + be + adj + (for O) + to V** | **S + be + adj + to V** (đổi chủ thể) |
| *It is difficult for me to learn Chinese.* | *Chinese is difficult for me to learn.* |
| **There + be + N + prep + N** | **N + have/has + N + prep** |
| *There are many clubs in my school.* | *My school has many clubs.* |
| **S + make + O + V** | **S + cause + O + to V** |
| *The noise made me wake up.* | *The noise caused me to wake up.* |
| **S + advise + O + to V** | **S + suggest + (that) + S + (should) + V** |
| *She advised me to join the club.* | *She suggested that I (should) join the club.* |
| **People + V + O** | **O + be + V3/ed** |
| *People speak English all over the world.* | *English is spoken all over the world.* |
| **They + say + that + clause** | **S + be + said + to V** |
| *They say that he is rich.* | *He is said to be rich.* |
| **S + need + V-ing** | **S + need + to be + V3/ed** |
| *The house needs cleaning.* | *The house needs to be cleaned.* |
| **S + be + responsible for + N** | **S + take + responsibility for + N** |
| *She is responsible for the project.* | *She takes responsibility for the project.* |
| **S + be + interested in + N/V-ing** | **S + be + fond of / keen on + N/V-ing** |
| *He is interested in music.* | *He is fond of music.* |
| **S + help + O + V** | **S + help + O + to V** |
| *Music helps me relax.* | *Music helps me to relax.* |

## 6.6. Mười lời nhắc cuối cùng

1. **Đọc kỹ đề trước khi viết** – gạch chân từ khóa; 30 giây đọc đề tiết kiệm 5 phút sửa bài.
2. **Không bao giờ để trống** câu trắc nghiệm hay câu tự luận.
3. **Bài viết là 1,5 điểm** – luôn dành 13 phút cuối cho nó, đừng để hết giờ.
4. **Chính tả là điểm** – *environment, responsibility, performance, independent* là 4 từ hay viết sai nhất.
5. **Đừng học thêm kiến thức mới** sau ngày thứ 9; chỉ ôn sổ tay lỗi.
6. **Ngủ đủ 7–8 tiếng** đêm trước khi thi; phần nghe cần tai tỉnh táo.
7. **Mang đủ đồ**: bút bi 2 chiếc, bút chì, tẩy, giấy nháp, đồng hồ đeo tay.
8. **Vào phòng thi, hít thở 3 lần** rồi mới mở đề – 10 giây này giúp giảm 30% lỗi bất cẩn.
9. **Làm phần mình giỏi trước** nếu đề phát không đúng thứ tự; nhưng **phải** theo dõi thời gian theo mục 1.4.
10. **Tin vào những gì đã luyện**: đề giữa kỳ 1 rất "trong sách" – 90% kiến thức đã nằm trong tài liệu này.
